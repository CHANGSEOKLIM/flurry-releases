# Flurry releases

Release files for Flurry for macOS. The app's source code is not here.

- Download: https://flurry-app.store
- Existing installs update themselves from this repository's latest release
  (`appcast.xml`, `Flurry-X.Y.Z.zip`). Every update is EdDSA-signed and the app is
  signed with Developer ID and notarized by Apple.
